# Lekker Claypot House Menu

An interactive digital menu for Lekker Claypot House, featuring bilingual dish descriptions, prices, and food photos.

## View the Menu

https://yingqluvtosleep.github.io/lekkerclaypot_house.menu/

## Features

- English and Chinese dish descriptions
- Seven food categories
- Dish prices and serving sizes
- Touch and keyboard navigation
- Responsive layouts for phones, tablets, and desktop screens
- Automatic featured-dish slideshow when idle

## Technology

Built with HTML, CSS, and JavaScript. No installation or build step is required.

Hosted for free using GitHub Pages.
